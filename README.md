## Stack Escolhida

- Backend: NestJS
- Frontend: React
- Banco de Dados Relacionais: PostgreeSQL
- Banco de Dados não relacionais: Redis

Porque escolhi cada um:
NestJS - Velocidade, Escalabilidade e manuntenção, porém é um canhão para uma mosca,
poderia ter feito o uso do express que é mais simples,
porém a escolha de uma ferramenta moderna, me levou a decidir usar o NestJS.

Frontend com Vite - Leve, rapido, escala e entrega o melhor do React, ainda que será uma SPA simples não um SEO completo que leve a usar NextJs.

Banco de Dados: PostgreeSQL - Gratuito, forte, otimizado e com documentação boa.
Redis - Utilizado para garantir fila para o sistema e cache para acesso a informações.

---

Bem com tudo isso começar modelar pelo banco de dados, é o ideal.
